Experiments

4.1 Experimental Setup

The experimental setting follows the rationale-based distillation framework used in the original study. A teacher LLM first provides label-rationale supervision, and a smaller student model is trained with both label prediction and rationale generation objectives. The difference in this paper is the data-preparation stage: before student training, the proposed boundary-aware pipeline filters and selects which generated rationales should be used as supervision.

We use the same two evaluation tasks as the original comparison: ESNLI for textual entailment and CommonsenseQA for multiple-choice commonsense reasoning. Accuracy is used as the evaluation metric for both datasets.

DatasetTaskOutputRole in this paper
ESNLINatural language inferenceentailment / neutral / contradictionMain textual entailment evaluation
CommonsenseQACommonsense question answeringmultiple-choice answerAdditional reasoning/generalization evaluation

The main proposed method is Boundary-Mix. It uses the shared boundary-aware pipeline to select one primary rationale from easy and boundary examples while dropping hard examples. Boundary-Bridge and Boundary-Specialist are included as same-family comparisons to analyze how different final selection rules affect the same shared pipeline.

The proposed Boundary-Mix method achieves 84.16% on ESNLI and 62.41% on CommonsenseQA. 4.3 Boundary Family Performance

We next compare variants from the same boundary-aware family. This comparison is important because the variants are not unrelated methods: they share candidate grouping, weighted voting, confidence estimation, difficulty-band assignment, and rationale scoring. Their difference is the final selection rule. Therefore, changes in performance can be interpreted as the effect of keeping one primary rationale, adding a bridge rationale, or focusing on specialist sources.

MethodFinal selection behaviorESNLICommonsenseQAInterpretation
BaselineNo boundary-aware filtering83.9360.36Original rationale-distilled student
Boundary-MixKeep easy + boundary; one rationale per example84.1662.41Main method; improves both datasets
Boundary-BridgeKeep easy + boundary and add bridge rationale when useful85.0660.52Best ESNLI, weak CommonsenseQA gain
Boundary-SpecialistFocus on boundary/bridge rows from specialist sources83.60training in progressESNLI-only result so far; useful as source-focused analysis

Boundary-Bridge gives the highest ESNLI score, which suggests that sentence-pair entailment can benefit from a second complementary rationale. However, its CommonsenseQA result is only slightly above the baseline, indicating that an additional rationale may introduce less useful associations for multiple-choice commonsense reasoning. Boundary-Specialist reaches 83.60% on ESNLI, lower than the baseline and the other two boundary variants, which suggests that focusing only on specialist/boundary-style sources removes too much clean supervision. Boundary-Mix is therefore the main method because it improves both completed datasets and gives the strongest CommonsenseQA result among the evaluated family variants.

4.4 Selection Behavior Across Family Variants

The distribution analysis is included only to explain why the family variants behave differently. Since the proposed method changes the selected training rationales, we need to show how each variant changes the training set. Boundary-Mix is conservative: it keeps one primary rationale and removes hard examples. Boundary-Bridge expands the selected set by adding second-view bridge rationales. Boundary-Specialist is much narrower and focuses mainly on bridge/boundary rows from selected sources.

This table explains the performance difference in Section 4.3. Boundary-Bridge increases coverage by adding many bridge rows, which is helpful for ESNLI but less stable for CommonsenseQA. Boundary-Specialist is the smallest ESNLI variant and excludes easy examples, which likely explains why its ESNLI accuracy drops to 83.60%. Boundary-Mix keeps the cleanest version of the selected data: one rationale per retained example, mostly high-agreement easy rows, plus a small number of boundary rows.

4.6 Qualitative Error Analysis

Finally, we include qualitative examples to show how the selection mechanism behaves at the example level. These cases explain what the easy, boundary, and hard bands mean in practice and why filtering is useful before student training.

Easy ESNLI case. Premise: “A young man wearing a backpack and dark glasses approaches the brick building where there is a bit of graffiti on the wall.” Hypothesis: “The young man has glasses on his face.” The selected label is entailment, with agreement count 7 and margin 6.17. This example is retained because the sources strongly agree and the selected rationale is directly grounded in the premise.

Boundary ESNLI case. Premise: “Two men, one standing and one seated on the ground are attempting to wrangle a bull as dust from the action is being kicked up.” Hypothesis: “A rodeo clown tries to save a rider from a bull.” The selected label is neutral, with agreement count 4 and margin 1.11. This example is retained as boundary supervision because the hypothesis is plausible but not guaranteed by the premise.

Dropped hard case. Premise: “A group of construction workers are working.” Hypothesis: “A group of guys outside.” The vote margin is 0.01. The rationale text may appear reasonable in isolation, but the candidate group is unstable. Boundary-Mix removes this example because the weak vote margin indicates unreliable supervision.

CommonsenseQA boundary case. Question: “Where did his wife ask him to look first when he complained of missing deodorant?” Selected answer: medicine chest. The selected rationale explains that medicine chest is where deodorant is usually kept. The example is retained as boundary because agreement is sufficient but not maximal.

These examples show the role of the boundary-aware module: it does not simply reward fluent rationales. It checks whether a rationale is supported by agreement among candidate sources and whether the example is stable enough to become student supervision.
